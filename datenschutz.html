Datenschutz

Hosting

Diese Website wird über GitHub Pages, einen Dienst von GitHub, Inc., bereitgestellt. Beim Abruf der Website können technisch erforderliche Verbindungsdaten verarbeitet werden. GitHub kann insbesondere IP-Adressen zu Sicherheits- und Betriebszwecken protokollieren.

Eigene Tracking- und Werbedienste

NBHandel setzt auf dieser Website derzeit keine eigenen Analyse-, Tracking- oder Werbeskripte ein. Es werden keine externen Schriftarten, Social-Media-Pixel oder Marketing-Skripte eingebunden.

Lokale Browser-Funktionen

Merkliste, Kaufcheck, Preisbeobachtung, Kaufmatrix und Datenverwaltung können freiwillige Eingaben ausschließlich im Local Storage des Browsers speichern. Dazu zählen z. B. Seitentitel, Links, Produktnamen, Preisbeobachtungen, Zielpreise, Bewertungen und Checklistenstatus. Diese Daten werden nicht an NBHandel übertragen und lassen sich über „Lokale Daten verwalten“ exportieren oder vollständig löschen.

Kamera- und Barcode-Scanner

Der Live-Barcode-Scanner fordert den Zugriff auf die Kamera nur nach einer aktiven Aktion des Nutzers an. Kamera-Stream und ausgewählte Fotos werden lokal im Browser verarbeitet und durch die NBHandel-Scannerfunktion nicht an NBHandel übertragen. Erkannte Codes können freiwillig als lokale Scan-Historie im Local Storage gespeichert werden und lassen sich über die Scanner-Seite oder „Lokale Daten verwalten“ wieder löschen.

Kontakt per E-Mail

Wenn Sie uns per E-Mail kontaktieren, verarbeiten wir die von Ihnen übermittelten Angaben zur Bearbeitung Ihrer Anfrage und der damit verbundenen geschäftlichen Kommunikation.

Betroffenenrechte

Soweit die gesetzlichen Voraussetzungen vorliegen, stehen Ihnen insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und Widerspruch sowie das Recht auf Beschwerde bei einer Datenschutzaufsichtsbehörde zu.
